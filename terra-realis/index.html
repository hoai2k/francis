Terra Realis

256× PBR textures + shaders for Minecraft Java

Drag to orbit · scroll or pinch to zoom

Texture pack

132 textures at 256×, from stone, soil and eight woods to gems, metals, the Nether, the End and plants. Each has LabPBR normal, height, AO and specular maps: gloss, real metals, light through leaves and grass, and glowing lava, magma and glowstone.

  • Java 1.20 – latest
  • LabPBR 1.3
  • ~50 MB

Shader pack

Realistic water (refraction, caustics, shore foam, depth absorption), parallax depth with self-shadowing, soft shadows, a physical sky, screen-space reflections, god rays, wet surfaces in rain, waving plants, bloom and filmic tonemapping.

  • Iris or OptiFine
  • LOW – ULTRA presets
  • Overworld, Nether, End

Install

  1. Texture pack: put Terra-Realis-256x.zip in .minecraft/resourcepacks, then enable it under Options → Resource Packs.
  2. Shaders: install Iris (Fabric/NeoForge) or OptiFine, put Terra-Realis-Shaders.zip in .minecraft/shaderpacks, and pick it under Options → Video Settings → Shader Packs.
  3. Use both together: the shaders read the pack's normal and specular maps. Try the HIGH profile first, ULTRA on a strong GPU.

Java Edition only. Bedrock uses a different format and isn't supported.

Textures
