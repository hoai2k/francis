Install

  1. Install Fabric Loader for Minecraft 1.21.1.
  2. Put Fabric API in your mods folder.
  3. Put starfall-arsenal-1.0.0.jar in the same folder.
  4. Launch the fabric-loader-1.21.1 profile. The weapons are in the Starfall Arsenal creative tab.

Warning: stars carve real craters. Try it in a test world first, or run /gamerule starfallTerrainDamage false to keep the blast and leave the terrain alone.

Controls & crafting

  • Right-click with a weapon to strike where you're looking.
  • J skips a cutscene, and when no film is playing it turns films on or off. You can rebind it.
  • Stellar Remote: amethyst shard, 4 iron ingots, a redstone block and a gold ingot.
  • Every impact drops Star Fragments. Craft them into the other weapons: Blade (2 fragments, 2 amethyst, diamond sword), Scepter (7 fragments, 2 blaze rods), Core (8 fragments, nether star).
